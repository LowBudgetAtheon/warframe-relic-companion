# Warframe Relic Companion

An Android app for tracking Warframe Prime parts, the relics that drop them, and rotating vendor stock.

**Download:** grab the latest `.apk` from [Releases](../../releases/latest).

- `docs/SPEC.md` is the full agreed feature plan.
- `docs/SETUP.md` covers the signing key, releases and how data updates.
- `legacy/prime-checklist.html` is the original prototype. The app keeps its look.
